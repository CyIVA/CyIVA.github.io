# 개발 현황

최종 갱신: 2026-09-05. 현재 단계: 로컬 릴리스 후보 구현·자동 게시 시나리오 검증 완료, GitHub 최초 배포 대기.

## 상태 기준

- 예정: 아직 구현하지 않음.
- 진행 중: 구현 작업 중.
- 구현 완료·검증 전: 코드 작성은 끝났으나 필요한 검증이 남음.
- 검증 완료: 명시된 완료 조건을 확인했고 근거를 기록함.
- 보류: 진행하지 않는 이유와 재개 조건을 기록함.

`npm run check`로 포스트 16개, 연혁 9개, 프로젝트 3개, 필수 필드·날짜·중복 slug·공개 링크·Liquid와 총 21개 정적 페이지를 확인했다. Git 기준점 `a8fc7e98a45d8b2f1e32a445b114646a162de2ca`와 콘텐츠 diff를 대조하여 기존 의미가 보존되었음을 확인했다. 임시 공개 글과 비공개 글을 각각 빌드하여 자동 게시 갱신과 배포 제외를 검증한 뒤 모두 제거하고 최종 빌드를 다시 통과했다. GitHub Actions YAML 파싱도 통과했다. 실제 원격 배포 성공 여부는 `main` push 후 확인해야 한다. 최신 Astro 7.3.1은 현재 Windows/Node 24 환경의 콘텐츠 동기화 과정에서 `picomatch` CommonJS 로딩 오류가 발생하여 5.13.10으로 고정했다.

4. 선택적으로 360px·키보드·라이트/다크 테마 정식 브라우저 QA를 수행한다.

## 보완할 자료와 기본값

- 소개 문구는 임시안이며 실제 경력·성과를 추정하지 않는다.
- HeimerRuri는 저장소와 기존 글에서 확인한 Python·TensorFlow/Keras·TorchIO·ANTsPy 정보를 반영했다. Procedural-Terrain의 세부 기술과 이미지는 확인 가능한 자료가 없어 비워 두었으며, 제공 시 Markdown만 보완한다.
- 카테고리 대소문자 통합, 현재 글 포함, 정렬·날짜 표시, 초기 테마, 팝업 해시 주소는 계획서의 기본안으로 진행 가능하다.
- 과거 URL 보존은 불필요로 확정. 별도 리디렉션 조사는 하지 않는다.
